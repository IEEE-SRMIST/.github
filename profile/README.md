# IEEE SRMIST

The IEEE Student Branch of SRM Institute of Science and Technology, Kattankulathur. We run workshops, hackathons, ideathons and talks that help students learn and build with new technology.

Our events include Concepto, HackTrix, EVOLVE, Protocol, TechTrek, TechnoZest, Hyperforge and HELLO CLOUD!

## What we build

Every IEEE SRMIST website and app, from event sites to registrations and recruitments, lives in one monorepo on one stack: Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, Motion and three.js, with Supabase where data is needed, hosted on Vercel. Each website has its own design, intro and animations.
